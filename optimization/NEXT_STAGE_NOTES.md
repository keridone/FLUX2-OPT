# 暂存优化思路与并发模型

更新时间：2026-08-19

## 当前推理执行模型

- 推理框架为 `stable-diffusion.cpp` 的 `sd-cli.exe`。
- 当前没有常驻推理服务或任务调度器；远端核查时没有运行中的
  `sd-cli.exe` 或 Python 推理进程。
- 基准与实验脚本为每个任务启动一次 `sd-cli.exe`，阻塞等待退出后再执行
  下一个任务。因此当前系统层面的任务并发度为 1，属于单任务串行执行。
- `sd-cli` 提供 `--batch-count`，但当前命令没有使用它。该参数用于一次调用
  生成多个结果，不代表已经具备多请求并发调度、跨请求动态 batching 或模型
  常驻复用能力。
- 每次 CLI 启动都要重新建立进程、读取/准备模型并创建计算资源。因此当前
  latency 基线同时包含进程启动与模型准备开销。

## 已确认的 Q8 瓶颈

- 热点：`mul_mat_q<8,128,0>`。
- 资源：255 registers/thread、58.88 KiB shared memory/block、无 spill。
- 活跃 warps：16.67%；SM throughput：54.30%；DRAM throughput：13.46%。
- 分类：占用率与计算/指令延迟瓶颈，不是显存带宽瓶颈。
- `mmq_x<=64` 端到端回退 3.86%，已拒绝。
- 单独将 `mmq_y` 改为 64 违反 `nwarps * tile_C::I == mmq_y`，已拒绝。

## 暂存的下一阶段优化方向

1. 保持 `mmq_x=128`、`mmq_y=128` 和 8-warp MMA 布局作为固定 control。
2. 分析 Q8 MMA accumulator 的活跃区间，减少不必要的同时存活值和寄存器
   生命周期；避免简单设置 `maxrregcount` 引入 spill。
3. 根据 NCU stall 数据优先处理 `wait`、`math pipe throttle`、`LG throttle`
   和 `MIO throttle`，检查加载、反量化、MMA 与写回之间的指令交错。
4. 每个候选先验证编译资源、CUDA 正确性和代表性 kernel，再执行固定任务的
   交错五次端到端 A/B；输出不一致的候选不得直接纳入系统。
5. 内核优化稳定后，单独建立“常驻模型 + 请求队列”工作包，区分：
   - 单请求延迟优化；
   - 多请求吞吐优化；
   - 显存允许时的多进程/多 stream 并发；
   - 可合批任务的静态或动态 batching。

并发改造不得与 Q8 内核实验混在同一基线中，以免模型加载复用或任务重叠
掩盖单任务 kernel 的真实性能变化。

## 并行可行性实验更新

- 单进程 `batch-count=4` 的吞吐为 0.2889 task/s，比 batch=1 提高 77.3%。
- 两个和三个独立 `sd-cli` 并发的吞吐分别降至 0.1433 和 0.1375 task/s，
  均低于单进程 0.1637 task/s。
- 暂停多进程并发方向；下一步实现一次模型初始化后处理多个不同任务的常驻
  runner，再评估异构 micro-batch。

### 常驻服务回归状态

- 常驻 `sd-server` 已完成 20 个任务 × 3 次回归，60/60 成功。
- 中位延迟 2.8586 秒，P95 2.9024 秒，吞吐 0.3494 task/s。
- 20/20 任务跨三次运行确定；预热后至结束显存变化 -9 MiB，无泄漏迹象。
- 生命周期脚本已验证。下一项转入文本条件和参考图 latent 缓存基线。

### 条件缓存基线

- 10 个完全相同请求中位延迟 2.8489 秒；10 个不同请求中位延迟 2.8552 秒，
  差异仅 0.0063 秒（0.22%），没有可观察的跨请求 cache hit。
- 服务端日志确认每个请求都重新运行 `encode_first_stage`（约 0.18 秒）和
  `get_learned_condition`（约 0.10 秒）。现有 EasyCache/UCache 等只复用去噪
  步骤内部计算，不覆盖这两个阶段。
- 两阶段合计约 0.28 秒，占服务端单次生成 2.71–2.72 秒的约 10.3%；这是缓存
  命中的理论上限，实际收益需要扣除 key、拷贝和缓存管理开销。
- 实施顺序定为：先做参考图 latent 的有界 LRU（内容哈希 + VAE/resize 参数作为
  key），再评估文本条件缓存。每项必须记录命中率、显存增量、延迟和像素一致性。
